Команда **только на чтение**: ничего не править и не коммитить, продукт и
проверки не запускать — только `git`, самопроверку хуков и проверку образцов
`tools/refs_check.py`. Читать разделы по заголовкам, а не документы целиком.
Весь экран — **не больше 12 строк**, словами продукта, без пересказа
подробностей.

1. **Ждёт вас** — первым блоком, по строке на то, что есть:
   - готово к проверке — пункты `готов к проверке` в `docs/BATCH.md` → `/done`;
   - выбор варианта — пункты `ждёт выбора` в `docs/BATCH.md` → `/start` в чате
     разработки (покажет лист сравнения с образцом и спросит окном);
   - вопросы — пункты `ждёт: …` и раздел «Вопросы владельцу» `docs/BATCH.md` →
     `/start` в чате разработки (спросит окном);
   - пришло — файлы в папках назначения из `docs/orders/*.md` и по путям
     долгов `docs/BLOCKED.md` (кадр-цель `docs/refs/<тема>/target-*`), которых
     нет в git → `/add` в чате разработки;
   - решения из `docs/BLOCKED.md`, из-за которых стоят пункты очереди,
     поимённо → `/need`;
   - образцы — `python -X utf8 tools/refs_check.py`, в контекст только список:
     недостающие картинки (сколько, темы) и неподтверждённые образцы, за
     которыми стоят пункты `[вид]` → `/need образцы`.

   Ничего нет — «Ждёт вас: ничего».
2. **Партия** — строкой: сколько пунктов в каждом состоянии (нет — «Партии
   нет»); сколько строк ждёт в «Пришло» и «Найдено по ходу» (их переносит чат
   замысла через `/idea`).
3. **Очередь** — первые три пункта «Очереди» `docs/ROADMAP.md` с метками;
   сколько всего `[можно]` и `[ждёт …]` (из них `[ждёт образца]`, если есть).
4. **Баги** — сколько записей в `docs/BUGS.md` и до трёх заголовков.
5. **Проверки** — состояние полигона и «Стенд вида» (если раздел есть) из
   `docs/TESTING.md`; «Последний полный прогон» из шапки `docs/BATCH.md`;
   сколько записей в «Принято без полной проверки» и «Нестабильные проверки»,
   если не ноль.
6. **Неладно** — блок только при находке, по строке на находку:
   - копии `../<папка>.wt/…` вне текущей волны (`git worktree list`);
   - пункт `в работе` с незакоммиченными файлами — если чат разработки сейчас не
     работает, это хвост после обрыва, что с ним делать, решит `/start`;
   - пункт `готов к проверке` без коммита `Пункт N:` после хеша снятия партии
     (`git log <хеш из «Снята … на <хеш>»>..HEAD --grep "Пункт N:"`);
   - неотправленные коммиты, если в `CLAUDE.md` коммиты отправляются;
   - есть `docs/refs/`, но нет `tools/refs_check.py` — «образцы проверить
     нечем → `/setup обновить`»;
   - «ассеты с некоммерческими правами: N» — файлы в git, у которых последняя
     строка `принят …` журнала `docs/orders/ledger.md` — с «Лицензией»
     `некоммерческая` (строки `заменён`, `удалён` и прочие не в счёт):
     `/release` их не выпустит → заменить через `/order`;
   - самопроверка хуков не зелёная: `python -X utf8 "<базовая папка
     скилла>/../../hooks/selftest.py"`, в контекст — только строку «Итог:»;
     код не 0 — «страж коммитов молчит: <что неверно>».

Последней строкой — один следующий шаг: `/done`, если есть готовое к проверке;
выбор варианта или ответ на вопросы партии — `/start`; `/start`, если очередь
не пуста; `/need`, если всё доступное стоит за владельцем; `/idea`, если
очередь пуста.
