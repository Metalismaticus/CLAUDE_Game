# Шаги 1, 2 и 5 — разговор

Окна — по `ASKING.md` (`../../reference/ASKING.md` от базовой папки скилла):
вопрос самодостаточен, 2–4 варианта, рекомендуемый первым с причиной; после
ответа — «Понял: …» и запись в `docs/SETUP-PLAN.md`. Факты (железо, версии,
установленное, что можно найти поиском) не спрашивать.

## Шаг 1. С чем пришёл владелец

Одно окно, два вопроса:

- «Где вы сейчас с идеей игры?» (header «Замысел»):
  - «Идеи нет» — спрошу, во что любите играть, и предложу 3 коротких замысла;
  - «Идея смутная» — соберём её выбором из вариантов;
  - «Идея ясная» — спрошу только недостающее;
  - «Уже есть наработки» — сначала прочитаю их, потом спрошу.
- «Как стартуем: быстро или подробно?» (header «Старт»):
  - «Быстрый старт (Recommended)» — до 4 раундов вопросов, бриф на страницу,
    окно игры сегодня;
  - «Подробно» — до 7 раундов, все документы заполнены.

Приложение или сервис вместо игры — те же вопросы его словами. «Наработки» —
прочитать их до вопросов (есть код — режим «существующий», `existing.md`).

## Шаг 2. Рассказ

Одним сообщением, не окном (ответ открытый): «Расскажите своими словами и
принесите всё, что есть: игры, на которые похоже, скрины (можно вставить в
чат), ссылки, заметки». При «Идеи нет» добавить: «во что любите играть и что
в этом цепляет».

Ответ — **дословно** в `docs/SETUP-PLAN.md`, раздел «Слова владельца»
(временный файл переживёт сжатие контекста и обрыв). Выписать рядом:
названные игры, моды, фильмы, видео, ссылки — образцы для шага 4 («как в X»
про управление, камеру, звук — образцы ощущения); сколько картинок вставлено
в чат; оговорки («наверное», «кажется») — пометкой `[предварительно]` у
фразы.

## Шаг 5. Раунды окон

Раунд — одно окно, ≤ 4 вопроса. Варианты — догадки из рассказа, паспортов
образцов и фактов шага 3, а не общий список; сказанное не переспрашивать.
Следующий раунд вытекает из ответов прошлого (ASKING, п. 8). Замысел
противоречит сам себе, платформам или железу — сказать в «Понял» и спросить
в следующем раунде.

| Раунд | Вопросы |
|---|---|
| (а) | жанр; камера и ракурс (от первого лица / из-за плеча / сверху / сбоку); платформы — что обязано работать с первого дня; размер (вечер / неделя / месяцы игры) |
| (б) | 30-секундный цикл: глаголы игрока (`multiSelect`); цель и провал; длина сессии |
| (в) | образцы — `refs.md`, п. 4: по каждой теме «что берём» (`multiSelect` составляющих паспорта); главный образец; шкала стилизации (Мультяшно / Стилизованно / Полуреализм / Реализм). ≤ 2 окон, считается одним раундом |
| (г) | стек — рекомендация по фактам шага 3 (что уже стоит, какая видеокарта) с причиной и запасной с ценой, не навязывать; «проба стека» первым пунктом, если ядро упирается в производительность (большие миры, воксели, толпы); у игры — компьютеры игроков (ниже). Выбран движок, которого нет в `env_check`, — сразу окно установки по `env.md`, п. 3–4 |
| (д) | исполнители заказов; сколько пунктов писать разом, когда будут проверки (2 (Recommended) / по одному); git — язык коммитов и README (ниже), приватность репозитория (только есть удалённый, а `gh` не сказал — `env.md`, п. 5), крупные файлы в LFS — только если есть git-lfs. ≤ 2 окон, считается одним раундом |

Компьютеры игроков (г), только игра — это решение владельца (кто сможет
играть), а не техника. Два вопроса; варианты, числа для description и
источник — «Цели для игроков» шаблона `docs/TESTING.md` («Бюджет
производительности»), ответ — туда на шаге 8, с датой, и в `levels`
`tools/perf_ref.json` (эталоны уровней меняются вместе). Образец:

- «На каком самом слабом компьютере игра должна идти — 1080p, низкие
  настройки, 30 кадров/с?» (header «Слабый ПК») — «Класс GTX 1060 / RX 580
  (Recommended)» — 4 ядра, 8 ГБ; так ставят планку похожие игры / «Слабее:
  GTX 1650, встроенная графика» — играть смогут больше людей, на низких
  проще картинка / «Сильнее: RTX 2060 / 3050» — низкие красивее, часть
  игроков отпадёт;
- «На каком компьютере игра должна идти плавно на высоких — 1080p, 60
  кадров/с?» (header «Хороший ПК») — «Класс RTX 3060 / 4060 (Recommended)» —
  6–8 ядер, 16 ГБ; самые частые видеокарты в Steam / «Класс RTX 2060 / 3050»
  — плавно у большего числа людей, высокие скромнее / «RTX 4070 и выше» —
  высокие богаче, плавно — у меньшего числа людей.

Процессоры уровней в `levels` от варианта не зависят (так у Minecraft Java
2026): слабый — i3-10100 / Ryzen 3 3100, хороший — i5-12400 / Ryzen 5 5600.
Эталона нет в таблице — строка по PassMark с URL и датой, пометка «оценка».

Машину владельца (ультра, под частоту его монитора) не спрашивать — по шагу
3, строкой «Решено за вас»; его прежнее решение о скорости (`DECISIONS.md`,
`CONCEPT.md`) главнее умолчания. Есть другая его машина слабее (ноутбук) —
строка «Не блокер» `BLOCKED.md`: «калибровка на <машине>: `/check замеры` на
ней, когда под рукой» (без окна).

Исполнители заказов (д) — что есть у владельца: только ручной заказ; ключ
OpenAI API в окружении (`api` для графики — платно и отдельно от подписки
ChatGPT); вход в Claude Design (`claude-design` для макетов). Включать только
названное; ключей и паролей не просить. Музыку делает генератор — вопрос о
его тарифе (вытекает из ответа — можно следующим окном): у бесплатного права
некоммерческие, платная подписка задним числом их не даёт; ответ — в паспорт
`docs/orders/music.md`.

Git (д) — два вопроса; ответы — в «Git» `CLAUDE.md` (правила —
`../../reference/COMMITS.md`):

- «На каком языке писать описания изменений (коммиты) в истории проекта?»
  (header «Коммиты») — «English (Recommended)» — на GitHub историю поймёт
  любой, отчёты вам — всё равно по-русски / «Русский» — история по-русски;
- «Описание проекта для GitHub (README) — на каких языках?» (header
  «README») — «en + ru (Recommended)» — README.md и README.ru.md, обновляются
  вместе / «en» — только английский / «ru» — только русский.

Проект с историей коммитов — в description «English» добавить «старые
останутся как есть».

**«Идеи нет»** — первым раундом окно «Какой замысел ближе?» из 3 питчей по
любимым играм владельца (одной строкой: жанр, главный глагол, чем цепляет);
смешать — заметкой.

**Быстрый старт** (≤ 4 раундов): (а), (б), (в), затем (г) и (д) одним окном —
стек, исполнители, язык коммитов, README; нужна приватность (`env.md`, п. 5)
— она вместо README, а README — `en + ru` `[допущение]`. У игры компьютеры
игроков — одним вопросом вместо README: «Для каких компьютеров делаем игру?»
— «Как у большинства игроков (Recommended)» (оба уровня по умолчанию) /
«Ниже: слабые ноутбуки» (слабый — GTX 1650, плавно — RTX 2060 / 3050) /
«Выше: новые видеокарты» (слабый — RTX 2060 / 3050, плавно — RTX 4070);
приватность тогда — вместо языка коммитов (`English` `[допущение]`). Прочее
— «Решено за вас» (писать по двое, без LFS). Движка выбранного стека нет —
после этого окна установка по `env.md`, п. 3–4. Чего не делаем, вид и звук —
допущениями `[допущение]` в плане: владелец поправит на шаге 7.

**Подробно** (≤ 7): (а)–(д) и до двух своих раундов — «чего не делаем»
(`multiSelect` из 3–4 кандидатов, отмеченные — осознанные отказы); «что нужно
из графики, музыки, звуков, макетов, текстов — и чем вы это делаете»;
противоречия замысла.

Ветка — `main`, если владелец не назвал другую: «Решено за вас».
