# Развёрнутый проект: `/setup обновить` и повторный `/setup`

`/setup` без «обновить» в развёрнутом проекте — окно «Проект уже развёрнут —
что делаем?»: «Обновить процесс (Recommended)» — перенести новый шаблон,
проектное не трогать / «Пересмотреть старт» — стек, образцы или очередь:
покажу, что изменится / «Ничего» — выйти.

## Обновить процесс

1. Идёт партия (`docs/BATCH.md` не «Пусто.») — не обновлять до `/done`,
   кроме недостающих `tools/` из п. 5 (скрипты и `perf_ref.json`, но не
   `code_check.py` с базой: база снимается с принятого кода): их разложить
   сразу, отдельным коммитом. В нужных файлах чужие незакоммиченные правки
   — сначала завершить их.

   же, что в `templates/CLAUDE.md`, — «процесс свежий», перейти к п. 5.

   - `CLAUDE.md`: «Команды», «Два чата», «Как приходит работа», «Метки

     «Правила процесса», «Как спрашивать владельца» (список — из
     комментария-метки шаблона); свои строки проекта в них — в список
     «пропадут» (п. 3). «Какой документ когда» и «Git» — только недостающие
     строки шаблона, строки проекта не трогать и в «пропадут» не включать;
     «Git» нет — вставить после «Запуск и проверка» (п. 7);
   - `docs/TESTING.md`: «Параллельная работа», «Правила каркаса», «Ловушки
     стека», «Принято без полной проверки», «Нестабильные проверки»; строка
     «Канонические ракурсы», столбец «Сколько идёт · предел» и строки
     «сценарий игрока», «стенд ощущения», «замеры», «сборка», «проверка
     сборки», «здоровье кода», «типы» в «Командах проверки»; правило зондов
     в «Замерах»; разделы `## Здоровье кода` (после «Замеров»), `## Сценарии
     игрока`, `## Стенд` (был `## Стенд вида`; в части «вид» — строки шаблона

     окно» и у продукта с миром в реальном времени (игра, стенд, просмотрщик)

     скелета: «Службы (автозагрузки):» — из `[autoload]` (пусто — «нет»),

     вас», таблицы «Где что» (по точкам входа) и «Копии, которые нельзя
     убрать» — пары без общего вызова (шейдер ↔ код на CPU, другой процесс),

     иначе пустая; вторая копия на другом языке того же процесса (Godot

     проверка стенда сверяет час с паспортом»; без выключателя мерок —

     `-Model` — «стенд: `-Model <путь>` — файл модели в кадре рядом с нашими
     вариантами»;
   - эталоны вида и проверки тона и края (файл эталонов из «Правил проекта»,
     проверки `*tone*`, краевой туман до края мира), снятые до приёмки света,

## Раздутый код — понемногу

Решение владельца: уборка рядом с обычной работой, не больше двух на
партию. **Сначала база, а не переписывание** — с неё новое не хуже, старое не
растёт, и код перестаёт разрастаться ещё до первой уборки. **Уборка — по
сигналу**, не «навести порядок»: находка сверх базы; находка в файле,
который правит пункт очереди; реестр или раннер — узкое место волн
(`scout`, горячий файл); третий повтор одного знания; пункт упал «не
удалось: код». **Шаг — одна цель**: поведение и проверки те же, свой
коммит; уборка общего узла — по одной в волне, первыми волнами.
**Порядок:** что разблокирует параллельность (реестры, раннер, корневой
файл) → копии, которые уже разошлись (это баг: сначала проверка) → вторая
копия на другом языке того же процесса (по частям) → мёртвое → крупные
файлы по частям, каждая часть — перед пунктом, который её правит (часть
больше порога — несколькими файлами) → типы (меньше ~150 объявлений
без типа — одной уборкой, больше — по папкам, большая папка — по файлам;
когда папки чисты — `untyped_declaration`, потом `unsafe_*` по папкам —
«Здоровье кода» `docs/TESTING.md`).
**Систему не переписывать:** по части за пункт, старую версию удаляет тот
пункт, который её заменил.
