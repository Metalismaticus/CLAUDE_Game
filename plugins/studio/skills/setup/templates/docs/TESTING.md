## Параллельная работа

**Состояние: {{не проверено | проверено | невозможно}} · предел: {{1}}**

`/start` делает независимые пункты одновременно, каждый в своей копии проекта
(git worktree), только при состоянии «проверено» и пределе больше 1. Решает
по пунктам разведчик `scout`; сомнение — по одному.

Предел — не больше числа полных проверок, которые машина тянет одновременно без
ложных провалов: 0 или 1 — всё по одному, 2, 3, 4 … — до стольких пунктов разом.
Меняется командой `/parallel N`, на один запуск — `/start all xN`; проверить
новый предел пробным прогоном — `/parallel проверить`.
