# Текущая партия

Файл ведёт чат разработки: `/start` записывает сюда снятый список, `/done`
очищает. Чат замысла его не правит — так два чата в одной папке не пишут в
один файл одновременно (`CLAUDE.md`, «Два чата»).

Пусто.

## Пришло — внести в очередь

Сюда пишет `/add`; переносит в `ROADMAP.md` и `BLOCKED.md` чат замысла.

## Найдено по ходу — внести в очередь

Сюда пишет координатор `/start`: что исполнители заметили вне своего пункта.
