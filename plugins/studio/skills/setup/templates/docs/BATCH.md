# Текущая партия

Файл ведёт чат разработки: `/start` записывает сюда снятый список, `/done`
очищает. Чат замысла его не правит — так два чата в одной папке не пишут в
один файл одновременно (`CLAUDE.md`, «Два чата»); замечание владельца о пункте
партии он пишет к пункту в `ROADMAP.md`.

Пусто.

## Общий пробел

Сюда пишет `/start all`, когда два пункта споткнулись об одну конкретную вещь
или два подряд «не удалось»: «<что>; задело N, M». Похожие пункты ждут
исправления; после него сначала идёт один пункт.

## Принято по умолчанию

Сюда пишет координатор `/start`: что решил сам, не спрашивая, — порядок и
способ работы. Строка: `Решил сам: пункт N — <что> — <почему>; отменить — при
/done` (для всей партии — `партия` вместо номера).

## Вопросы владельцу

Только то, что `/start all` задаёт окнами в конце запуска: замеры сейчас или
позже и то, что нельзя ни решить без владельца, ни отложить (вопросы «что
делать» идут в «Решения» `BLOCKED.md` — `/need`; сюда — только если там была
чужая незакоммиченная правка). Неотвеченное остаётся здесь, в «Решения»
`BLOCKED.md` его переносит `/done`.

## Пришло — внести в очередь

Сюда пишет `/add`; переносит в `ROADMAP.md` и `BLOCKED.md` чат замысла.

## Найдено по ходу — внести в очередь

Сюда пишет координатор `/start`: что исполнители заметили вне своего пункта.
