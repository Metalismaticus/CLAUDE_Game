# Заказ: звуки (`sfx`)

Звук чаще **подбирается**, чем генерируется: заказ — это точное описание
файла, по которому владелец найдёт его в библиотеке или сделает генератором.

## Паспорт

| Поле | Значение |
|---|---|
| исполнитель | вручную |
| источник | {{библиотеки, генератор, запись}} |
| куда сохранять | `{{assets/audio/sfx/…}}` — в заказе всегда полный путь файла |
| формат | {{WAV или OGG, 44.1 кГц, моно для звуков в мире, стерео для интерфейса}} |
| файлы заказов | `docs/prompts/sfx-NN.md` |

## 1. Характер

{{общее ощущение звуков продукта: сухие или с пространством, механические или
мягкие, насколько громкие относительно музыки}}

## 2. Формат

- длительность: {{обычно до 1 с для интерфейса, до 3 с для событий}};
- начало без тишины, конец без щелчка;
- вариации: {{сколько вариантов у часто звучащего звука и как они называются —
  `name_01..03`}};
- как продукт находит файл: {{сканированием папки по имени — тогда достаточно
  положить файл; или записью в ресурсе — тогда нужен пункт очереди}}.

## 3. Строка заказа

| Поле | Что писать |
|---|---|
| файл | полный путь |
| что за звук | событие в продукте, которое его вызывает |
| характер | материал, высота, атака, хвост — словами |
| длительность | |
| как часто звучит | раз в минуту или десять раз в секунду — от этого зависит, сколько нужно вариаций |

## 4. Приёмка (`/add`)

Контейнер, длительность, каналы, нет тишины в начале и щелчка в конце, громкость
рядом с уже принятыми звуками; права на использование названы.
