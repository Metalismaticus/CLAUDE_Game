# Заказ: текстура (`texture`)

Текстура поверхности — земля, камень, кора, ткань. Перед заказом сверить
папку назначения и бесплатные библиотеки (CC0): ambientCG, Poly Haven.
Платное — только после «да» владельца окном.

## Паспорт

| Поле | Значение |
|---|---|
| исполнитель | вручную |
| источник | {{библиотеки CC0 (ambientCG, Poly Haven); генератор — чем пользуется владелец}} |
| куда сохранять | `{{assets/textures/<материал>/…}}` — в заказе всегда полный путь файла |
| формат | PNG |
| файлы заказов | `docs/prompts/texture-NN.md` |
| образцы к заказу | 2–3 принятые текстуры рядом по смыслу; образец вида — паспорт темы в `docs/refs/` |

## 1. Стиль

{{стилизация по шкале `docs/refs/INDEX.md`; насколько рисованная; крупность
рисунка; палитра — из паспорта темы. Что видно на кадре стенда, а не на
плоском файле.}}

## 3. Разрешение и плотность

- разрешение — степень двойки: {{1024, 2048}};
- плотность текселей — {{N пикселей на метр}}: соседние поверхности не
  отличаются резкостью;
- один повтор покрывает {{… м}}.

## 4. Бесшовность

- плитка без шва по обеим осям;
- без заметного повторяющегося пятна при 3×3 повторах;
- {{переход к соседнему материалу, если он нужен — отдельной маской}}.

## 5. Постоянная часть заказа

```
<материал>

Бесшовная текстура, вид строго сверху, ровный рассеянный свет без теней и
бликов. Стиль: {{…}}. {{разрешение}} px, PNG. Один повтор — <метров>.
Карты: {{цвет, нормали (OpenGL), шероховатость …}}.
Без текста, подписей, водяных знаков.
```

В `<материал>` — что за поверхность, крупность рисунка в метрах, чем
отличается от соседнего материала.

## 6. Проверка перед отправкой

- сказано «бесшовная» и «без теней и бликов»;
- названы разрешение, размер повтора в метрах и нужные карты;
- источник и лицензия, если текстура готовая;
- назван **полный путь файла**.

## 7. Приёмка (`/add`)

Разрешение — степень двойки; шва нет (3×3 рядом); карты с верными именами,
нормали и прочие — не sRGB, направление зелёного канала как у движка;
плотность текселей рядом с соседними материалами — снимок на стенде вида (нет
стенда — из «Команд проверки»). Затем «после правки ресурсов» из
`docs/TESTING.md`.
