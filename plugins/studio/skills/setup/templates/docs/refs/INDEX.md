# Образцы вида

Как должна выглядеть игра — картинками, а не прилагательными. Здесь — общее
для всех тем; по теме — паспорт `docs/refs/<тема>.md`, её картинки — в папке
`docs/refs/<тема>/`. Паспорт в состоянии `черновик` пишет разбор образца
(агент `reference`, зовут `/idea` и `/setup`); подтверждает владелец окном;
выбор по листу сравнения ложится в «Журнал» паспорта. Пункт `[вид]` по теме
без подтверждённого паспорта стоит `[ждёт образца]`.

## Картинки

Имена в папке темы:

- `owner-<дата>-<n>.<ext>` — снимки и скрины владельца;
- `ref-<игра>-<n>.<ext>` — найденные кадры (jpg, png, webp; URL — в паспорте);
- `target-<n>.<ext>` — кадр-цель, в т. ч. перерисовка (заказ `art`, подвид
  «кадр-цель»): направление, а не пиксельная цель;
- `accepted-<дата>.<ext>` — принятый кадр нашей игры;
- `sheet-<дата>.png` — листы сравнения (`tools/look_sheet.py`).

Длинная сторона — не больше 2560 px, у листов `sheet-` — до 2576. Все ли
картинки на месте — `python tools/refs_check.py` (код 0 — да). Первый кадр
`/setup` — в `docs/refs/setup/` («Окружение» `docs/TESTING.md`).

Образцы лежат в git, если репозиторий приватный. Репозиторий: не проверено.
Публичный — чужие кадры `ref-…` в `.gitignore`, в паспорте — ссылка на
источник.
