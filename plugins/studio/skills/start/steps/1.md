# 1. Подготовить основу

Глава протокола `/start` — читать, дойдя до этого этапа; после сжатия контекста перечитать. Пути — от базовой папки скилла (там лежит `SKILL.md`), как в нём; «раздел N» — глава `steps/N.md`.

1. `git status` и ветка. Ветка не та, что в `CLAUDE.md` («Два чата»), —
   остановиться и спросить окном. Чужое незакоммиченное не трогать и не
   коммитить: `.md` и `docs/refs/` (кроме листов, `variant-` и `accepted-`
   пунктов партии) — работа чата замысла, не спрашивать; незнакомые код или
   ресурсы — описать и спросить окном (`/start all` — не спрашивать: в отчёт).
2. **Пришедшие файлы заказов — первыми, не своими руками:** файлы вне git в
   папках назначения `docs/orders/*.md` и по путям долгов `docs/BLOCKED.md`
   (в `docs/refs/` — только `target-*`) — `assets`: «Разбери пришедшее по
   инструкции `<путь>`» (`../add/SKILL.md` от базовой папки скилла).
   Картинки и промты не открывать; в партию они не попадают.
3. **Партия уже есть в `docs/BATCH.md`** — продолжить её, новую не снимать.
   Сверить строки с git; коммиты пункта —
   `git log <хеш>..HEAD -E --grep "^(Пункт|Item) N:"`, хеш — из строки
   «Снята … на <хеш>» (номера в каждой партии свои), шаг 3б — по
   постоянному сообщению (`стенд`, `основа —`, `варианты …, выбор K`):
   - `в работе` с коммитом пункта (у `[вид]` — этого шага) — сделан:
     `готов к проверке`, у `[вид]` — следующий шаг 3б; коммит только в
     `wave/p<N>` копии — слияние (3а; коммит вариантов — после выбора); `[вид]`
     на выборе без коммита основы — на шаг «основа», круг 1/3; с пометкой
     «возврат с выбора K на <хеш>» — основа сделана, только если коммит
     `основа —` есть в `<хеш>..HEAD` (иначе — основа кругом 2/3 с замечанием);
   - `в работе` с незакоммиченными не-`.md` файлами — не перезапускать;
     сначала раздел 4, «Прерывание». Одиночный `/start` — окно «Пункт N
     прервался, правки остались — что с ними?»: «Продолжить проверкой
     (Recommended)» — `reviewer` по ним; «Откатить и начать заново» — как «не
     удалось» в разделе 4; «Оставить как есть». `/start all` — сразу проверка;
   - `ждёт выбора` (партия до 0.10.5) — выбрать самому по 3б, п. 3 («Вижу:»
     к пункту нет — сначала «Смотреть самому»; слова владельца о листе —
     главнее образца), дальше — 3б, п. 4;
   - `ждёт: …` — ответ есть (`docs/DECISIONS.md`, у вопроса в сценарист —
     по пометке «Партия <дата>, пункт N») или дан сейчас — раздел 4; нет —
     окном (в `/start all` — в конце); вопрос со строкой в «Решения»
     `BLOCKED.md` не переспрашивать — ответ даст `/need`; «Вопросы
     владельцу» — по разделу 4;
   - работы и вопросов нет — предложить `/done` и остановиться; копии в
     `../<папка проекта>.wt/` вне текущей волны — перечислить
     (`slot_pool.py list`; после обрыва — сначала `sync`, 3а).
