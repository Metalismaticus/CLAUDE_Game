# Как спрашивать владельца

Общие правила для всех команд studio, где есть вопросы. Скилл ссылается на
этот файл одной строкой и правила не копирует. Владелец — не программист,
работает в приложении Claude для компьютера.

## Правила

1. Любой вопрос с выбором — окном `AskUserQuestion`. В чат — только короткое
   пояснение до окна (≤ 5 строк: длинный текст окно закрывает) и итог после.
   Длинное — в файл, в чат — путь к нему.
2. Спрашивать только о решениях владельца: замысел, вкус, приоритет, приёмка,
   деньги, необратимое. Факты искать самим; технику решать самим и называть
   строкой «Решено за вас».
3. Окно: 1–4 вопроса, 2–4 варианта. «Другое» не добавлять — оно есть само,
   вместе с полем заметки. Можно выбрать несколько — `multiSelect`. Больше
   четырёх вариантов — делить на вопросы поровну (5 = 3 + 2); остался один —
   обычный вопрос «<суть>: …?» с двумя вариантами.
4. Вопрос самодостаточен (Desktop не показывает `header`): номер пункта и суть
   в тексте вопроса. Тексты вопросов в одном окне разные — ответы привязаны к
   тексту. `header` всё равно нужен: ≤ 12 символов.
5. label — 1–5 слов; description — одна строка «что будет, если выбрать».
6. Рекомендуемый вариант — первым, label кончается `(Recommended)`, причина — в
   description.
7. «Пока не знаю» — законный ответ: вопрос уходит в «Решения» `BLOCKED.md`,
   необратимое по умолчанию не делается.
8. Не больше двух окон подряд, если следующее не вытекает из ответа на
   прошлое; дальше — итог «записал так-то». Цепочка, где вопрос вытекает из
   ответа (`/done`: выбор → причины → проход по пунктам), не ограничена.
9. После ответа — строка «Понял: …» и запись **дословно** в нужный документ
   (заметки владельца — тоже дословно).
10. Картинки — никогда в окне: сначала путь к файлу (владелец щёлкает — файл
    открывается справа во весь размер) или `SendUserFile` с
    `display: "render"`, если инструмент есть; потом окно.
11. Субагенты не спрашивают: инструмента у них нет. Нужен ответ — блок
    «Вопрос владельцу» в конце итога; координатор превращает его в окно без
    пересказа:

    ```
    Вопрос владельцу: <вопрос одной строкой, самодостаточный, словами продукта>
    - <вариант> (Recommended) — <что будет, если выбрать>
    - <вариант> — <что будет>
    Пока нет ответа: <что агент сделал или что делать дальше без ответа>
    ```

    `Вопрос владельцу (можно несколько): …` — вопрос с `multiSelect`;
    `(Recommended)` в таком блоке не обязателен.
12. В `/start all` вопросы не прерывают партию: копятся в `docs/BATCH.md`,
    «Вопросы владельцу», задаются окнами в конце (≤ 2 окон; окна выбора по
    листу `[вид]` — по одному на пункт, сверх них); неотвеченное остаётся
    там, в `BLOCKED.md` его переносит `/done`.

## Запасной путь

- Окна нет (ошибка, VS Code, окно не появилось) — тот же вопрос нумерованным
  списком текстом плюс «или напишите словами».
- Пустой ответ или Skip — повторить один раз; снова пусто — как «пока не
  знаю». Кроме `multiSelect`, где скилл назвал пустой выбор ответом
  («ничего»): это ответ, не повторять.
- «Другое» без текста — спросить словами и остановиться.
- Свободный ответ вместо выбора — главнее вариантов.

## Образец

```
Пункт 3, забор у дома: какой высоты?            ← вопрос, header «Забор»
- По пояс (Recommended) — двор виден с дороги, как на вашем образце
- В рост — двор скрыт, дом выглядит закрытым
```

Отчёты и вопросы — словами продукта: не «rebase», «ff-only», имена констант и
файлов кода, а что видно и что изменится в игре или приложении.
